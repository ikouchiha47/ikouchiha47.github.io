For the sliding window here are key things:
- A new element entering the window can either be greater or smaller than the
  present max
- If its greater, then no element can be greater then no older element in the
  window can ever be greater than the new element
- If not, any one of the element lower than the present max in present window,
  and **appears after the persent max**.
  can become the max in future window

The candidate list, is to maintain this possible greater element. The candidates
get permanently discarded once we see an element greater than the elements in
the candidate list.
